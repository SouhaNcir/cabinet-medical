# Cabinet Médical

Application web PHP de gestion de cabinet médical : patients, rendez-vous,
consultations et ordonnances. Deux rôles : médecin et secrétaire.

Projet de fin de module DevOps : Licence 3 DSI, ISET.

## Structure

- `app/` : code de l'application (contrôleurs, modèles, vues)
- `public/` : point d'entrée web et ressources (CSS, JS)
